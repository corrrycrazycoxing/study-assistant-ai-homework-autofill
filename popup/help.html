Choose your pace

These pace modes and timing preferences are shared across supported platforms. Platform-specific settings such as pause-after-fill remain separate.

Instant Auto

Enters answers as soon as they are ready. It still waits for the chatbot and the website to save, but adds no review countdown.

Continues automatically

Timed Auto

Shows a countdown before each answer entry and before continuing to check, save or move on. When time runs out, Auto continues by itself.

Continues automatically

Human pace

Uses an adjustable AI estimate of reading and working time for the question. Faster, Typical and More deliberate adjust that estimate. AI response time counts toward the wait.

Continues automatically

Guided Answers

Asks AI for the current question and shows the answer and explanation. You enter the answer and use the website’s own controls yourself. Choose Guide me again on the next question.

You enter answers yourself
Pause after fill is a separate switch.

With it on, the run pauses after entering the question so you can review it before checking or saving. Turn it off for continuous Instant Auto, Timed Auto or Human pace. Guided Answers never fills fields or advances.

How are the countdowns chosen?

Use the AI’s suggested review budget or your configured fallback time. The budget is split across answer fields or journal cells. “Before advancing” sets the separate wait before checking, saving or moving on. You can pause a countdown, choose Continue now, or stop.

These waits are review time. They do not pause a quiz timer or change what activity the website can record.

Use the main controls

Walkthrough
Use Walkthrough at the top of Help for a guided tour with highlighted controls. It opens Settings with you, explains the four pace cards, and never starts a run. Skip walkthrough or Escape closes it; your preferences stay saved.
Start Auto
Reads the question, asks the AI, fills supported answers, and checks or advances when the platform supports it. Your pace and Pause after fill settings apply.
Ask AI
Gets an answer for the current question and shows it in the preview. Auto Fill after Ask AI can fill it too; older McGraw adapters keep their existing Ask AI flow.
Edit answer
After Ask AI with Auto Fill off, edit a supported prepared answer before filling. Save changes updates the preview; Fill answers enters it. Choices and existing validation still apply. Journal rows cannot be added or removed. Original SmartBook and older Connect do not have this editor.
Fill answers
Enters the current prepared answer when it matches the question and its controls.
Stop run / Stop all
Cancels pending automation. Values already entered remain on the page. Closing this panel does not stop a run.
Resume Auto
Continues after a Pause after fill review. Resume saved run is for an interrupted run; review partly entered answers first.
Check work and final submission

Check work can use an attempt. McGraw Connect MAP, Pearson, Canvas and MindTap leave final assignment submission to you. Original SmartBook and older Connect keep their existing behavior.

Run Pearson homework and lessons in order

Open Pearson’s course Assignments page and choose Go through homework & lessons in the Full Course Mode card. It checks Pearson’s score for each homework or lesson before opening it. Only a confirmed 0%, unstarted assignment is eligible. Course Mode uses Start when available or the first question link when that is Pearson’s route. Scored assignments, assignments Pearson labels Resume, and items whose status cannot be confirmed are left untouched and listed for review. Tests, exams and quizzes are excluded.

  1. Choose an Auto pace in Pearson settings. Guided Answers is for one question at a time and cannot run a whole course.
  2. Optionally turn on Continue without review pauses to skip the after-fill review pause during this course run.
  3. Course Mode enters answers and uses Pearson’s Save between assignments. It does not use final Submit.
  4. Question work can continue while associated required media remains incomplete. Pearson may record media completion after its media route returns, even if the media tab appears blank; check the status in Pearson. Course Mode leaves media listed until verified.
  5. If a question has missing source material, an unsupported field, an unreadable image or an answer Pearson does not confirm, Course Mode leaves it unanswered and moves on when Pearson provides a safe Next control.
  6. At the end, a large review window lists skipped questions, assignments needing review and media still to review. Use Open assignment to return to the exact Pearson assignment and check its media status.
Skips are not successful answers.

Skipped questions remain unanswered for you to review. If the extension cannot navigate safely, or Pearson does not confirm its Save, Course Mode stops and asks for your attention.

Run MindTap homework in course order

Open the Cengage MindTap course outline. Course Mode queues visible assessment activities MindTap explicitly marks Not started. Apply It · grade-counting work is selected by default. Optional checkboxes add Study It, Learn It, and Other sections, including explicit practice activities. Reading/media, quizzes, tests, exams, submitted work and in-progress work are left out. The Course Mode card appears on the course activity list, stays hidden during a solo assignment, and returns at course-run review checkpoints. If no eligible activity is visible on the outline, it will not start.

  1. Choose Instant Auto, Timed Auto or Human pace in Settings. These pace and working-speed preferences are shared across platforms; Guided Answers is for one question at a time.
  2. Choose the activity sections you want in the fixed MindTap Course Mode card. Apply It is the default; enable other sections if you want them included. It opens eligible assignments through MindTap’s native activity control.
  3. Auto enters supported answers and follows the existing Aplia assignment flow. Unsupported or unclear work stops for your attention rather than being guessed.
  4. Optionally select Skip per-question review pauses for continuous filling. The assignment overview still stops for your review and manual submission before advancing.
  5. When the question flow reaches the assignment overview, review it and use MindTap’s own submit control. Then use Continue to next assignment.
  6. The ending review reports assignments that need attention. Course Mode does not submit or grade the full assignment for you.
Scope and verification

This mode currently covers the MindTap Aplia course outline and Aplia assignment player. CNOWv2, SAM and other Cengage players are not included. It has been checked against the live course outline without opening or answering assignments; end-to-end course completion still needs a safe, unstarted test assignment.

Update an unpacked installation

A GitHub release does not replace files in an unpacked Chrome extension automatically. When the panel reports a newer version, use the release ZIP or the optional command-line helper, then reload the extension and its open tabs.

  1. Manual: open the latest release ↗, download and extract its ZIP, then load that extracted folder in chrome://extensions (remove the older unpacked copy first if you want one installation).
  2. Helper: from a project source checkout, run python3 scripts/update-unpacked.py "/path/to/the/folder/Chrome-loaded" --check. If it finds an update, run the same command with --apply instead. The helper updates that existing folder; it is not bundled with the extension ZIP.
  3. Open chrome://extensions, click Reload on Study Assistant, then reload the assignment tab and each connected AI tab.
The panel’s Chrome extensions button only opens the reload page.

It does not download or install the GitHub update. Finish the file-update step first.

Other features

Background operation / Watch automation
By default, AI tabs work while your current tab stays visible. Turn on Watch automation to follow the tab switches. Click any AI link to open or switch to that chatbot.
NotebookLM readings — why use it?
For questions tied to assigned readings, a source-based answer can match the course’s terminology and examples more closely than a general chatbot answer. NotebookLM uses your selected sources and offers citations to verify. Add the assigned materials, select the relevant sources and keep the notebook open. It can still be wrong or lack the needed source. How source-based chat works ↗
Prefer NotebookLM uses the selected notebook’s readings, then a regular chatbot formats the result for input. If no notebook is open, a regular chatbot is used. Choose one notebook when several are open.
Question pictures
Optionally sends a crop of visible question graphics to Gemini or ChatGPT. Enable capture from the extension icon on the assignment first. Picture capture needs the assignment visible. Upload support is experimental.
Activity & recovery
The stage strip shows current activity. Recent activity keeps eight temporary observed updates while the panel is open. Attention needed explains connection problems and offers explicit recovery actions. It never repeats a save or grading action automatically. Go to assignment focuses the tab; Stop all first if you want to take over an active run.
Answer preview / Nerd mode
The preview shows answers and plain explanations. Nerd mode reveals the structured response for troubleshooting.
Replace existing answers
For newer McGraw Connect, allows prepared answers to replace conflicting entries. Otherwise they are preserved and the run pauses with an action to enable replacement.
Saved progress
Keeps local run markers for recovery. It does not guarantee that an answer was correct. Interrupted saves or grading need manual review.
Settings by platform
Pace and working-speed preferences are shared across McGraw, Pearson, Canvas and MindTap. Pause-after-fill, notebook preference and other platform options stay separate. Watch automation applies to all of them.

In regular Auto, unsupported controls pause for manual entry. Pearson Full Course Mode leaves unsupported questions unanswered and lists them for review. MindTap Course Mode opens eligible not-started homework in order and leaves assignment review/submission to you. Review all answers before final submission. This is an independent local extension.
