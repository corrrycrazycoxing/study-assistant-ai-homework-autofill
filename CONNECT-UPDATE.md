# Connect support in 2.0

The McGraw 1.1 fix is included. New Connect MAP runs at ezto.mheducation.com/ext/map with native choice/text/select fields and the embedded accounting journal worksheet. Account menus and numeric cells use the native worksheet model, with strict transaction addresses, balanced rows and retained-value verification. The assistant records journal entries and navigates only in a started run; final submission remains manual.

2.0 adds review pacing before fields or journal rows and before recording/advancing, optional question graphics, the shared NotebookLM flow and per-platform settings. SmartBook and older EZTO adapters remain separate and share the same AI connection. Complex unsupported controls stop for manual work. See README.md and VERIFICATION.md.
