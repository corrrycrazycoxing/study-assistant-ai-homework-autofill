Study Assistant 2.7.0

MindTap Course Mode adds a fixed course-page launcher for the Cengage MindTap outline. It scans the visible outline and queues only assessment activities explicitly marked **Not started**. **Apply It · grade-counting work** is selected by default. Checkboxes can add **Study It**, **Learn It**, and **Other** practice/assessment sections for users who want a broader run. Reading/media activities, quizzes, tests, exams, in-progress work and submitted work stay out.

Course Mode opens selected activities through MindTap’s native outline controls, then hands the assignment to the existing Aplia Auto flow. An optional per-question review-pause setting supports continuous filling; the mode still stops at each assignment overview so you can review and submit with MindTap’s own control before continuing. The final review identifies skipped work and offers a button to reopen each skipped activity. Final assignment submission remains manual. The feature currently supports the MindTap Aplia course outline/player; CNOWv2, SAM and other Cengage players are not included.

Instant Auto, Timed Auto, Human pace and working-speed preferences are shared across McGraw, Pearson, Canvas and MindTap. Pause-after-fill, notebook selection and other platform-specific options remain separate.

The shared MindTap outline parser and queue were tested with synthetic DOM cases for visible/unstarted, in-progress, submitted, selected practice, quiz and media examples. A local mock page is included for manual preview. The live MindTap outline markup and section labels were inspected read-only. The open course had no eligible Apply It assignment, so no assignment was opened, answered, graded or submitted. Browser security policy blocked opening the local mock in a browser, so visual/browser-level mock verification remains outstanding.

This release also retains the Pearson Course Mode, linked-source handling, version status and updater instructions introduced in 2.6.0. The ZIP extracts to one **Study-Assistant-2.7.0** folder. In Chrome Extensions, enable Developer mode, choose **Load unpacked**, and select that extracted folder. For future updates, see the README’s **Updating an unpacked installation** instructions.
